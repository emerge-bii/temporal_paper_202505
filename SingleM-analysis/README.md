# SingleM analysis scripts for the EMERGE temporal paper

## SingleM_alpha

Analysis of SingleM-OTU-based alpha diversity across habitat, depth and time.
Includes richness, Shannon, Pielou's evenness, Simpson's index and inverse Simpson's index.

## SingleM_appraise_summary

Summary of SingleM appraise results, including proportion of reads mapping to assemblies and MAGs at species and genus levels.

## SingleM_appraise_details

Description of SingleM appraise results, breaking down the predicted taxonomy of OTUs that are missing from the MAGs.

## SingleM_ordinations

Bray-Curtis NMDS ordinations and dbRDA based on SingleM OTUs.
Includes comparison of alpha diversity with habitat, depth, soil/air temperature and time.
